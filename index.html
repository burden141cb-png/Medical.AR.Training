CO-22

Claim/service covered by another payer (COB)

Step-by-step resolution:

  1. Check primary payer EOB/ERA.
  2. Verify COB loops in your PM system.
  3. Post primary payment and adjustments.
  4. Prepare secondary claim with correct COB info.
  5. Submit as a new claim (not a replacement).
  6. Document resolution in patient notes.

MA130

Unprocessable claim due to missing/invalid info

  1. Identify missing or incorrect information.
  2. Correct the claim details.
  3. Submit as a new claim (do not appeal).
  4. Document steps in the patient record.

MSP Code

Medicare Secondary Payer code

  1. Determine if Medicare is primary.
  2. Select the correct MSP code based on reason (0, 12, 14, 15, etc.).
  3. Populate COB loops in PM system with Medicare info.
  4. Submit claim to secondary payer including Medicare info.

CO-45

Charge exceeds fee schedule / contracted maximum

  1. Check payer’s fee schedule.
  2. Compare billed charge to allowed amount.
  3. Post adjustment for the difference.
  4. Do not bill patient for CO-45.

PR-2 Coinsurance

  1. Identify patient responsibility per ERA/EOB.
  2. Check if patient is Medicare/QMB — may not be billable.
  3. Post coinsurance in PM system if allowed.
  4. Document any adjustments or write-offs.

PR-3 Copay

  1. Identify copay from secondary payer ERA/EOB.
  2. Check if patient is Medicare/QMB — may not be billable.
  3. Post copay in PM system if allowed.
  4. Document in patient account notes.
